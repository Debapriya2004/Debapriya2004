# 👨‍💻 About Me

Hi! I'm **Debapriya Das**, a Cloud & DevOps enthusiast from India 🇮🇳, obsessed with the journey of an application from `git push` to production, running at scale.

I love automating everything that can be automated, building resilient infrastructure, and treating servers like cattle — not pets. 🐄

```yaml
current_focus:
  - Linux & Shell Scripting

  - Kubernetes (K8s)
  - CI/CD Pipelines (GitHub Actions, Jenkins)
  - Infrastructure as Code (Terraform)
  - Nginx & Reverse Proxies
  - Monitoring & Observability
```
